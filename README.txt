TejoERP WhatsApp Group Contact Extractor — v5.0.0

INSTALL
1. Extract this ZIP into a folder.
2. Open chrome://extensions in Chrome.
3. Remove the older WhatsApp Group Contact Extractor version.
4. Enable Developer mode.
5. Click Load unpacked and select this extracted folder.
6. Refresh web.whatsapp.com.

USE
1. Open the target WhatsApp group.
2. Open Group Info so that “View all (N more)” is visible.
3. Click the TejoERP extension icon.
4. Click “Extract Contacts”.
5. Keep the WhatsApp tab and extension popup open until extraction finishes.
6. Click “Export Last Result (CSV)”.

BRANDING
- Uses the supplied TejoERP wordmark and icon16/icon32/icon48/icon128 assets.
- favicon.ico is included in icons/ for reference.
- The popup uses TejoERP navy/teal/green styling and a compact Chrome-popup layout.

SCOPE / LIMITATIONS
- The scanner clicks the visible “View all (N more)” control and searches only inside
  WhatsApp's “Search members” dialog.
- It does not intentionally scroll the chat list, conversation, or other page panels.
- It can export only numbers WhatsApp exposes in the participant list to your account.
- It cannot reveal hidden/private phone numbers.
- WhatsApp changes its UI periodically; verify the exported contacts and counts.
- Names are associated on a best-effort basis.
- Processing is local in the browser; no contacts are sent to an external server.
- Use contact details only where you have an appropriate lawful basis and permission.
